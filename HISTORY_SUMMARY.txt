🎯 HOW TO USE:

1. VIEW HISTORY:
   → Open extension popup
   → Scroll through recent analyses
   → See last 20 entries

2. COPY A RESULT:
   → Find entry you want
   → Click "📋 Copy" button
   → Paste anywhere (Ctrl+V)

3. VIEW FULL RESULT:
   → Click "👁️ View" button  
   → Opens in page overlay
   → Copy or read full response

4. DELETE ENTRY:
   → Click "🗑️ Delete" button
   → Entry removed immediately
   → Cannot be undone

5. CLEAR ALL:
   → Click "🗑️ Clear" in header
   → Confirm action
   → All history deleted

═══════════════════════════════════════════════════════════════════════

💾 STORAGE:

• Maximum entries:     100 (auto-cleanup)
• Display limit:       20 most recent
• Storage location:    Chrome Local Storage
• Storage size:        ~1-2 MB for 100 entries
• Auto-cleanup:        Keeps last 100, removes oldest

═══════════════════════════════════════════════════════════════════════

🔒 PRIVACY:

Stored Locally:
✅ Your questions/inputs
✅ AI responses  
✅ Analysis metadata
✅ Timestamps

NOT Stored:
❌ API keys (separate)
❌ Browsing history
❌ Personal data (unless in input)
❌ Screenshots (only results)

Security:
• Local storage only (never leaves browser)
• No cloud sync
• User controlled (delete anytime)
• Chrome encrypted

═══════════════════════════════════════════════════════════════════════

🧪 WHAT GETS TRACKED:

Each analysis saves:
• Input text or capture info
• Full AI response
• Analysis mode used
• Platform (OpenAI, Claude, etc.)
• Timestamp (ISO format)
• Type (text or image)

Example:
{
  "timestamp": "2024-11-16T10:30:00Z",
  "type": "text",
  "input": "What is AI?",
  "result": "AI stands for...",
  "mode": "auto",
  "platform": "openai"
}

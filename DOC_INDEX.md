## 📱 Documentation Format Guide

### Markdown Files (.md)

- Rich formatting with headers, lists, tables
- Best for reading in GitHub or Markdown viewers
- Most comprehensive information

### Text Files (.txt)

- Plain text, printable
- Quick reference cards
- No special formatting needed

### JavaScript Files (.js)

- Executable code examples
- Copy-paste ready
- Run with: `node filename.js`

### Shell Scripts (.sh)

- Automated tasks
- Run with: `./filename.sh`
- May need: `chmod +x filename.sh`

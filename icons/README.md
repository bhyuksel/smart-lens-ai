# Extension Icons

Please add the following icon files to this directory:

- `icon16.png` - 16x16 pixels (browser toolbar)
- `icon48.png` - 48x48 pixels (extension management page)
- `icon128.png` - 128x128 pixels (Chrome Web Store)

## Icon Design Guidelines

### Theme

- Modern, professional look
- Use purple/blue gradient colors (#667eea, #764ba2)
- Include a lens or magnifying glass symbol
- Add AI/brain element if space allows

### Tools

You can create icons using:

- Adobe Illustrator
- Figma
- Canva
- Online icon generators

### Placeholder

Until you create custom icons, you can use any placeholder icons or generate them at:

- https://www.favicon-generator.org/
- https://realfavicongenerator.net/

### Quick Setup

For development, you can temporarily use emoji-based icons:

1. Create a simple colored square in any image editor
2. Add a 🔍 emoji or lens symbol
3. Export at the required sizes

The extension will work with any PNG files at the correct sizes.

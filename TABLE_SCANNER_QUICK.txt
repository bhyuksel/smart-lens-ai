📋 EXPORT FORMATS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  📄 JSON     → Structured array of objects (APIs, programming)
  📊 CSV      → Comma-separated values (Excel, spreadsheets)
  ⚙️  TOML     → Configuration format (config files, Rust/Go)
  📝 Markdown → Table syntax (documentation, README files)

🚀 HOW TO USE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1️⃣  Click SmartLens AI extension icon
  2️⃣  Click "📊 Scan Data Table" button (green)
  3️⃣  If multiple tables → select one from list
  4️⃣  Choose format: JSON / CSV / TOML / Markdown
  5️⃣  Click action button:
      • 📋 Copy     → Copy to clipboard
      • 💾 Download → Save as file
      • 🤖 Analyze  → Send to AI for insights

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Source Table:
┌─────────┬─────┬───────────┐
│ Name    │ Age │ City      │
├─────────┼─────┼───────────┤
│ Alice   │ 30  │ New York  │
│ Bob     │ 25  │ London    │
└─────────┴─────┴───────────┘

JSON:
[
  {"Name": "Alice", "Age": 30, "City": "New York"},
  {"Name": "Bob", "Age": 25, "City": "London"}
]

CSV:
Name,Age,City
Alice,30,New York
Bob,25,London

TOML:
[[records]]
name = "Alice"
age = 30
city = "New York"

[[records]]
name = "Bob"
age = 25
city = "London"

Markdown:
| Name | Age | City |
| --- | --- | --- |
| Alice | 30 | New York |
| Bob | 25 | London |

🎯 BUTTON ACTIONS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  📊 Scan Data Table (green button)
     └─ Opens table scanner, finds all tables on page

  Format Buttons:
     └─ JSON    → Object array with key:value pairs
     └─ CSV     → Comma-separated, Excel compatible
     └─ TOML    → Config format with [[records]]
     └─ Markdown → Table with | pipes |

  📋 Copy
     └─ Copies formatted data to clipboard
     └─ Ready to paste anywhere

  💾 Download  
     └─ Saves file with correct extension
     └─ .json / .csv / .toml / .md

  🤖 Analyze with AI
     └─ Sends table data to selected AI
     └─ Gets insights and analysis

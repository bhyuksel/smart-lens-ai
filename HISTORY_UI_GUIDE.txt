📋 COPY BUTTON:
  • Copies full AI response to clipboard
  • Shows "✅ Copied to clipboard!" status message
  • Works with Ctrl+V to paste anywhere

👁️ VIEW BUTTON:
  • Opens full response in page overlay
  • Closes popup automatically
  • Shows complete, untruncated result
  • Has X button to close overlay

🗑️ DELETE BUTTON (on entry):
  • Removes that specific entry
  • Shows "🗑️ Item deleted" status
  • History list updates immediately
  • Other entries remain intact

🗑️ CLEAR BUTTON (in header):
  • Asks for confirmation: "Are you sure?"
  • If confirmed: Removes ALL history
  • Shows "🗑️ History cleared" status
  • Cannot be undone!

💡 QUICK TIPS:

1. RECENT FIRST
   → History is sorted newest to oldest automatically

2. PREVIEW vs FULL
   → Popup shows preview (200 chars)
   → Click "View" for complete response

3. COPY SHORTCUT
   → Copy button for quick clipboard access
   → Faster than manually selecting text

4. COLOR CODING
   → Quickly identify analysis type by color
   → Platform badge shows which API was used

5. STORAGE MANAGEMENT
   → Automatic cleanup keeps last 100
   → No manual maintenance needed

6. SEARCH TIP
   → Use browser's search (Ctrl+F) in overlay
   → Or copy to notes app for advanced search

7. BACKUP
   → No built-in export yet
   → Can manually copy important results

8. TESTING
   → Perform a few analyses to populate history
   → Try different modes to see color variety

│ Error Message                │ Solution                             │
├──────────────────────────────┼──────────────────────────────────────┤
│ "Invalid key format"         │ Copy the entire key, no spaces       │
│ "Incorrect API key"          │ Generate new key from platform site  │
│ "Insufficient credits"       │ Add billing/credits to account       │
│ "Rate limit exceeded"        │ Wait 60 seconds, try again           │
│ "Connection timeout"         │ Check internet/firewall settings     │
│ "Authentication failed"      │ Verify key hasn't been revoked       │

┌─────────────────────────────────────────────────────────────────────┐
│ 📝 WHAT GETS TESTED                                                 │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  1. Key Format Validation                                           │
│     • Correct prefix (sk-, AIza, etc.)                              │
│     • Proper length and characters                                  │
│                                                                     │
│  2. API Connectivity                                                │
│     • Can reach the API endpoint                                    │
│     • Authentication works                                          │
│                                                                     │
│  3. Response Quality                                                │
│     • Sends: "What is 2 + 2?"                                       │
│     • Expects: "4" (or similar)                                     │
│     • Token usage reported                                          │
│                                                                     │
